Resources

Work others can actually reuse.

Validated setups, scripts and reference material from HECS research. A result that cannot be reproduced is a claim, not a finding — so the intent is to release the things that make reproduction possible.

HECS begins formal operation in November 2026. Items marked In preparation are being written up for release; nothing on this page is published yet. This page exists so the commitment is on the record and so collaborators know what to ask for.
Planned releases

What the lab intends to share.

Released under permissive licences wherever the underlying work allows it, with a citation request rather than a restriction.

CONVERGE case setups for hydrogen release and dispersion

Reference case files for compressible hydrogen jets transitioning to buoyancy-dominated plumes, with the mesh and AMR settings that actually resolve the near-field, plus the validation cases they were checked against.

Case files · mesh/AMR notes · validation data
In preparation

User-defined functions for battery thermal runaway

UDFs and submodel notes developed for vent-gas and hot-particle modelling of Li-ion thermal runaway, including the interfaces required to couple electrochemical and thermal behaviour.

UDF source · coupling notes · usage guide
In preparation

Post-processing scripts for spray and jet diagnostics

Python tooling for extracting penetration length, cone angle and plume boundaries consistently from both Schlieren imaging and CFD output — so experiment and simulation are measured the same way.

Python · works on imaging and CFD output
In preparation

Constant-volume combustion chamber data

Flame-kernel growth and pressure-trace datasets for hydrogen-enriched natural gas under laser and spark ignition across initial pressure, temperature and mixture strength, in a documented format.

Datasets · metadata · linked to the source publications
