PACKAGE CONTENTS

- HECS_Lab_Logo_Transparent_1024.png / 512 / 256 : transparent web-ready sizes

IMPORTANT ABOUT SVG
The approved logo began as raster artwork. To honor the instruction not to modify the design, the SVG files embed the approved PNG artwork rather than redrawing or auto-tracing it. This guarantees exact appearance, but the internal artwork is not editable vector paths. A true path-based vector redraw would require reconstructing/tracing the artwork and can introduce small visual differences.

No visual redesign has been applied in this package.
